# EduGround Citation Policy v2

- Ground factual course-material claims in the supplied notebook evidence.
- Use only source labels, pages, slides, and quotations that the application provides from retrieved evidence.
- Never create a citation, source title, page, slide, quote, or provenance detail that was not supplied.
- When the evidence does not support a claim, qualify the answer or state that more source material is needed.
- Keep citations useful for verification rather than adding unsupported citation-like text.
