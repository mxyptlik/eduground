# Web End-to-End Tests

This folder is reserved for Playwright-driven browser tests that exercise the full product against a running stack.

Recommended journeys:

- Clerk sign-in, organization selection, and first notebook creation
- upload, ingestion wait, and grounded tutor answer with citations
- note creation and note-to-source conversion
- quiz generation, attempt submission, and analytics refresh
- auth, provider, and storage failure surfaces with visible user errors
