EDUGROUND / EVALUATION LAB

Review instructions.

Read the evidence. Make the decision. Keep the record. Everything happens in your browser.

1Download the review materials

Download the ZIP once and unzip it to a folder you can find again:

Download review inputs (ZIP)

Inside: one <course>.dataset.json, one <course>.evidence.json and one <course>.similarity.json per course, plus a similarity cheat-sheet and README.

2Open the review workspace

Open review workspace

No account needed. Decision data stays in your browser; nothing is uploaded anywhere.

3Import your assigned course files

  1. In the workspace click “Import datasets, evidence or review bundle”.
  2. Select the files for your assigned course(s): the .dataset.json and the .evidence.json (and, optionally, the .similarity.json).
  3. In a hurry? You can select every file in the ZIP at once — all courses in a single import — and then work through them with the Course filter. Importing one course at a time behaves identically.
  4. You will see a confirmation like “Complete indexed evidence loaded for …” — that is required to see the full source chunks.
Session rule: evidence files must be re-imported every time you fully close or reopen the browser. Your review decisions are kept and restored automatically.

4Review each question

  1. Click a question row to open it: you will see the question, the corrected-reference box, the cited quote, and the full indexed source chunk (the cited quote is highlighted in yellow inside it).
  2. Check the claim against the source: does the quoted passage genuinely support the question and its reference answer?
  3. Set a Decision: Accept, Flag or Reject. Enter your reviewer name. For Accept, tick the attestation checkbox. Flags and rejections require notes explaining why.
  4. Press Save review. You can edit your decision later; every revision is recorded.
BadgeMeaning
⚠ sim 0.54Soft similarity alarm: the question/answer scored low semantic similarity to its quoted sentence. It is not an error — read it adversarially (especially check that the quote really supports the question). Broad “synthesis” questions legitimately score lower.
No badgeRoutine review. Still verify the claim; the alarm cannot see logic errors.

5Export and return your review

  1. When finished (or periodically as backup), click “Export review bundle” — it downloads one JSON file containing all your decisions.
  2. Return that JSON file by email to favoursam49@gmail.com in the same message as the course(s) you reviewed.
  3. Optional: “Export table CSV” gives a spreadsheet view.

6Troubleshooting

  • The full chunk is not shown → the evidence file for that course is not imported in this session. Import <course>.evidence.json.
  • “This dataset is already imported” → normal when re-selecting files; your decisions are preserved.
  • Wrong or lost decisions → every choice autosaves to this browser; use “Export review bundle” before switching computers.

7Data handling

Review materials contain course content. Keep them on your device, do not redistribute them, and return only the exported review bundle.
